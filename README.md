
HTML & CSS Project Series

This repository contains a series of beginner-friendly projects built using HTML and CSS. The goal of this series is to practice fundamental frontend skills, improve layout design, and create visually appealing static web pages without using JavaScript.

Project 1: Tribute Website

The tribute website is a simple single-page site dedicated to a historical or inspirational figure. It includes a brief biography, an image, and styled content using CSS. The layout is responsive and uses semantic HTML tags for accessibility and clarity.

Project 2: Job Application Form

This project is a styled job application form built using HTML5 form elements and CSS. It includes various input types such as text fields, radio buttons, checkboxes, date pickers, and a submit button. The layout is clean and mobile-responsive.

How to Use

To view any project:

1. Clone the repository to your local machine.
2. Open the project folder (e.g., project1-tribute).
3. Open the index.html file in your browser to see the result.
4. You can also open the file using Visual Studio Code and run it with the Live Server extension for a better development experience.

Tools Used

* HTML5

Project Folder Structure

Each project is organized in its own folder. Inside each folder, you'll find:

* index.html (main file)
* style.css (styling)
* assets/ (contains images or screenshots)
